Cara Memeriksa ID Game Sebelum Top Up

Top up dapat gagal atau masuk ke akun yang salah jika ID pemain atau server tidak sesuai. Luangkan waktu untuk mencocokkan data sebelum pembayaran.

Temukan ID dari profil resmi

Buka game dan lihat halaman profil, pusat akun, atau menu top up resmi. Jangan menyalin ID dari chat yang tidak dikenal karena nama tampilan bisa berbeda dari ID pemain.

Cocokkan server dan wilayah

Beberapa game memisahkan pemain berdasarkan server atau wilayah. Pastikan pilihan server, negara akun, dan mata uang sesuai dengan produk yang akan digunakan.

Periksa nominal dan bukti

Pastikan nominal sesuai kebutuhan, lalu simpan bukti pembayaran dan nomor pesanan. Jika terjadi masalah, gunakan kanal bantuan resmi penyedia dan jangan mengirim OTP.

Lihat juga panduan transaksi digital dan cara menghindari phishing.
